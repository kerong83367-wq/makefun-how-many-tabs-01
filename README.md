How many tabs do I have open? 87. The program writes the number to
`/output/entry.txt`; a judge compares counts two at a time and picks the more
surprising one.

## Run it

```sh
MAKEFUN_OUTPUT_DIR=out node main.ts
```

Node 22, standard library only, no network. Two runs produce byte-identical output.
